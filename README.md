# Shoe Reader

Blackjack card-counting app for home games with friends: live count in seven systems, an enter/leave signal, bet sizing, the best move for every hand (basic strategy plus index plays), side-bet values, and a step-by-step guide for counting a real deck.

It is an installable web app that works offline.

## Install on your phone

- **iPhone:** open the site in Safari → Share → **Add to Home Screen**
- **Android:** open the site in Chrome → ⋮ → **Install app**

## Note

Counting cards in your head is legal. Using a phone or any device to count or decide plays at a casino table is a crime in Nevada (NRS 465.075) and many other places. This app is for home games, practice and learning.
